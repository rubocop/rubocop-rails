### Bug fixes

* [#1662](https://github.com/rubocop/rubocop-rails/pull/1662): Fix an error for `Rails/ReadWriteAttribute` when a `read_attribute` call is nested inside another attribute call. ([@viralpraxis][])
* [#1660](https://github.com/rubocop/rubocop-rails/pull/1660): Fix an incorrect autocorrect for `Rails/RakeEnvironment` when a task declares its arguments without an array literal, or declares an empty dependency list. ([@viralpraxis][])
* [#1657](https://github.com/rubocop/rubocop-rails/pull/1657): Fix version-gated cops using `minimum_target_rails_version` to respect `AllCops: TargetRailsVersion` so that an explicitly configured version takes precedence over the lockfile and enables these cops in projects without a lockfile. ([@koic][])

### Changes

* [#1655](https://github.com/rubocop/rubocop-rails/pull/1655): Resolve `AllCops: TargetRailsVersion` within RuboCop Rails itself instead of relying on RuboCop core, in preparation for the removal of `TargetRailsVersion` support from RuboCop core in RuboCop 2.0. ([@koic][])
